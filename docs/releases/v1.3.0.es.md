# Portfolio API v1.3.0

Asistente consistente y contratos de publicación

- Perfil profesional curado separado del contenido de proyectos; preguntas personales pueden responderse sin depender del repositorio editorial.
- Continuidad conversacional en repreguntas, cambios de proyecto y referencias al empleo; historial acotado y métricas sin texto de conversaciones.
- Exclusión de posts futuros o inválidos del conocimiento remoto y local.
- Errores de Resend correctamente propagados en contacto; pruebas unitarias y conversaciones de integración ampliadas.

## Publicación y compatibilidad

Esta release conserva las rutas y contratos públicos. Las mejoras se integran mediante merge commit para preservar los commits por tema. El tag anotado se publica sobre el commit integrado después de confirmar los despliegues.

Orden de despliegue: Cloud → API → frontend. No adelantar el frontend a sus protecciones de publicación y soporte de historial.
