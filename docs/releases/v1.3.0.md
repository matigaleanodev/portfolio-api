# Portfolio API v1.3.0

Production publication and quality improvements

- Curated professional profile separated from project content; professional questions can resolve without the editorial repository.
- Conversation continuity across follow-ups, project switches and employment references, with bounded history and text-free metrics.
- Future and invalid posts excluded from remote and local editorial context.
- Resend errors propagated by contact handling, with expanded unit and conversation integration coverage.

## Publication and compatibility

Public routes and contracts remain compatible. Merge commits retain the topic-based history. The annotated tag is published on the integrated commit after deployments are confirmed.

Deployment order: Cloud → API → frontend. Publish the frontend after publication guards and conversation history support are deployed.
